# PEDAL RUSH 🚴

Jogo arcade 2D com cenário de cidade brasileira, obstáculos, moedas, pulo, pontuação e conexão Bluetooth FTMS com bicicletas como a KWIKWI.

## Como jogar

Abra o site em HTTPS pelo Chrome Android ou desktop compatível. Toque em **Conectar bicicleta** e escolha KWIKWI; em seguida, **Jogar**. Alternativamente, use **Modo teste**, segure Espaço ou Acelerar e pule com seta para cima.

O serviço Bluetooth é `0x1826` e a característica de notificações Indoor Bike Data é `0x2AD2`. A velocidade vem em centésimos de km/h. A distância é calculada pelo jogo.

## Publicar

Em Settings > Pages, selecione Deploy from a branch, main, / (root). O jogo estará disponível em `https://luanbarbosa12278-max.github.io/Regulador-sono/` após a publicação.
